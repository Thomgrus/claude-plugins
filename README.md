# claude-plugins

Claude Code plugins by Thomas GRUSON.

```bash
claude plugin marketplace add Thomgrus/claude-plugins
```

| Plugin | What it does | Install |
|---|---|---|
| [english-coach](plugins/english-coach) | Checks each message you type with Haiku and shows English tips above the prompt, with a progress pane across sessions | `claude plugin install english-coach@tgruson-public` |
| [codemap](plugins/codemap) | Finds a local repository from its name or a business term, and records every repository Claude clones | `claude plugin install codemap@tgruson-public` |

Each plugin lives in `plugins/<name>/` with its own README.
